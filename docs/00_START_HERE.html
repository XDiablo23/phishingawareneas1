Security

Security Review & Secure-Coding NotesNEW..\SECURITY.md
The full secure-coding review: trust model, controls in place (PBKDF2 + timing-safe auth, pinned-alg JWT, tenant isolation, metadata-only ingestion, encryption at rest for every integration secret, httpOnly-cookie sessions with double-submit CSRF, least-privilege per-tenant service tokens), the hardening applied (security headers + CSP, JWT expiry enforcement, CSV formula-injection escaping, cross-tenant event guard, upload caps, HTML sanitizer, SSRF scheme checks, fail-closed-in-prod), residual/accepted risks, and a production deployment checklist. 119 tests + a clean dependency audit.
